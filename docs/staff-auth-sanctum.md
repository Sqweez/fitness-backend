# Авторизация сотрудников через Sanctum

Подготовлено локально. На сервере эта замена JWT не применялась. Выпуск бэкенда и обновление конфигурации фронта должны выполняться согласованно; старые JWT перестанут работать и сотрудникам потребуется войти заново.

- `POST /api/auth/login` принимает прежние `{login, password}` или `{pass}`. Номер логина очищается прежним `unmask_phone`; ведущие нули кода карты сохраняются. Вход разрешён только активным, не удалённым сотрудникам.
- Ответ: `{ "access_token": "id|token", "token_type": "bearer", "expires_in": null }`. Токен хранится в БД в виде хеша, действует до отзыва; refresh не используется. В Nuxt выбрана обычная `local`-схема с Bearer, `maxAge: false`, данные пользователя берутся из `/auth/me`.
- `GET /api/auth/me` требует токен сотрудника и сохраняет прежний плоский ответ: пользователь, клубы, роли и разрешения. JSONResource используется без изменения административного контракта.
- `POST /api/auth/logout` требует токен сотрудника и удаляет только текущий токен. Другие сессии сотрудника сохраняются. Ответ и сообщение прежние.
- `/api/auth/refresh` удалён. Nuxt не вызывает refresh; при 401 очищает сессию. Ошибки сети и 403 не вызывают выход.
- `api` использует Sanctum с provider `users`, `mobile` — с provider `clients`. Вход через session-cookie отключён для этих token-only guards. Токен клиента не открывает административные методы и наоборот.
- Деактивация сотрудника блокирует дальнейшие запросы с его токеном; удалённый сотрудник не проходит проверку provider. Права по ролям не меняются.

Для сотрудников используется уже существующая таблица `personal_access_tokens`; отдельная миграция не добавляется. `tymon/jwt-auth` и осиротевшие зависимости удалены из Composer, остальные версии пакетов не обновлялись. Общий `APP_KEY` сохраняется. `JWT_SECRET` больше не нужен, но старое значение в серверном `.env` само по себе не мешает работе.

Контроллер содержит только HTTP-ответы, валидация находится в `LoginRequest`, вход и отзыв токена — в `StaffAuthService`, сервис внедряется через конструктор.
